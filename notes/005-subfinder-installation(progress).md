================================================================================
005 - SUBFINDER INSTALLATION
================================================================================

ЦЕЛЬ:
Установить и протестировать Subfinder в Kali Linux для перечисления поддоменов.

================================================================================
ПОПЫТКА 1: ЧЕРЕЗ APT (НЕУДАЧНО)
================================================================================

Проверка наличия:
$ subfinder -version
Результат: Command 'subfinder' not found

Попытка установки:
$ sudo apt install subfinder
Результат: Unable to locate package subfinder

Вывод: Subfinder отсутствует в стандартных репозиториях Kali.

================================================================================
ПОПЫТКА 2: ПРОВЕРКА GO (НЕУДАЧНО)
================================================================================

Проверка наличия Go:
$ go version
Результат: Command 'go' not found

Попытка установки Go:
$ sudo apt install golang-go
Результат: Unable to locate package golang-go

Проверка репозиториев:
$ cat /etc/apt/sources.list.d/kali.sources
Результат: Конфигурация присутствует

Проверка обновления пакетов:
$ sudo apt update
Результат: Could not connect to mirror.wane.kr - Connection refused

Вывод: Проблема с зеркалом Kali Linux.
Статус: IN PROGRESS

================================================================================
ПОПЫТКА 3: ЧЕРЕЗ GO INSTALL (УСПЕШНО ✓)
================================================================================

Проверка Go:
$ go version
Результат: go version go1.25.1 linux/amd64

Вывод: Go уже установлен в системе (не требует переустановки).

Установка Subfinder из исходного кода:
$ go install -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest
Результат: Успешная загрузка 100+ модулей и компиляция v2.16.0

Добавление в PATH:
$ export PATH=$PATH:$(go env GOPATH)/bin

Финальная проверка:
$ subfinder -version
Результат: [INF] Current Version: v2.16.0
           [INF] Subfinder Config Directory: /home/kali/.config/subfinder

Статус: ✓ УСПЕШНО

================================================================================
ИСПОЛЬЗОВАНИЕ
================================================================================

Базовое сканирование поддоменов:
$ subfinder -d example.com -o subdomains.txt

Вывод результатов:
$ cat subdomains.txt

Сканирование с выводом в консоль:
$ subfinder -d example.com

================================================================================
КЛЮЧЕВЫЕ МОМЕНТЫ
================================================================================

1. Go был предустановлен на Kali (1.25.1)
2. Subfinder не доступен через apt (используется go install)
3. Бинарник сохраняется в $GOPATH/bin
4. Требуется добавление PATH для постоянного доступа
5. Конфиг Subfinder: ~/.config/subfinder

================================================================================
ПОСТОЯННАЯ КОНФИГУРАЦИЯ PATH
================================================================================

Если PATH не сохраняется после перезагрузки, добавить в ~/.bashrc:

export PATH=$PATH:$(go env GOPATH)/bin

Применить изменения:
$ source ~/.bashrc

================================================================================
БЫСТРАЯ УСТАНОВКА (ОДНА КОМАНДА)
================================================================================

$ go install -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest && \
  export PATH=$PATH:$(go env GOPATH)/bin && \
  subfinder -version
